# 🏁 Country Marble Race - YouTube Shorts Studio Suite

An interactive, vertical (9:16 - 1080x1920) YouTube Shorts Country Marble Race simulator with 197 sovereign nation flags, 8 downhill obstacle stages, tournament regional filters, dynamic difficulty presets, live Shorts video recorder, and AI viral title generator!

## 🚀 Features
- **Vertical 9:16 Canvas (1080x1920 @ 60FPS)**: Tailored for YouTube Shorts & TikTok.
- **197 Sovereign Nations Dataset**: High-resolution flag textures.
- **8 Intense Downhill Stages (9,450px Gauntlet)**:
  - Stage 1: Dense Plinko Peg Field (Y: 480 - 1350)
  - Stage 2: Banked Zig-Zag Slopes with Spring Rebounds (Y: 1400 - 2500)
  - Stage 3: Opposing Quad-Windmills (Y: 2600 - 3700)
  - Stage 4: Double Choke Bottleneck (Y: 3800 - 4800)
  - Stage 5: Pinball Labyrinth (Y: 4850 - 6200)
  - Stage 6: The Gravity Funnel & Twin Cross-Spinners (Y: 6250 - 7450)
  - Stage 7: Double Pendulum Sweepers & Quad Matrix (Y: 7500 - 8700)
  - Stage 8: The Grand Finale Gateway & Checkered Finish (Y: 8720 - 9450)
- **🌍 Regional Selection**: All World (197 flags), Asia (49 flags), Africa (54 flags), Europe (44 flags), Americas (35 flags), Oceania (14 flags).
- **⚡ Course Difficulty**: Easy (Chill Roll), Normal (Balanced), Hard (Full Chaos).
- **🎥 Built-in Shorts Video Recorder**: Capture directly to 1080x1920 60FPS WebM video with auto-stop on 1st place victory.
- **✨ AI YouTube Title Generator**: Dynamic high-CTR titles, 1-click clipboard copy, and viral tags.
- **🔊 Procedural Synthesizer**: 100% Web Audio API sound effects without external audio files.

## 🛠️ Getting Started
Open `index.html` in any modern browser, or run the local development server:

```bash
node server.js
```

Visit `http://localhost:8080/`.
